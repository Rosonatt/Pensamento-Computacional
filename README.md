# Computational Thinking

This repository contains materials and exercises for the Computational Thinking course. The content is designed to strengthen problem-solving skills and the application of programming concepts through practical examples.

## Repository Structure

The repository is organized into the following folders:

- **P1**: Content and activities from the first part of the course.
- **P2**: Content and activities from the second part of the course.
- **estrutura de repetição**: Exercises focused on loops and repetition structures in programming.
- **simulado**: Simulations and exercises used in lessons or tests.
- **.gitattributes**: Configuration file for Git attributes.

## Technologies Used

- **Python**: Used for solving programming problems and exercises.
- **Jupyter Notebook**: Used for interactive coding and problem demonstrations.

## Requirements

Before you start, ensure you have the following tools installed:

- [Python 3.x](https://www.python.org/downloads/)
- [Jupyter Notebook](https://jupyter.org/install)
